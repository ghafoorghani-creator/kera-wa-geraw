# کرا و گرو غفور

وب‌اپلیکیشن فارسی/دری برای ثبت قراردادهای کرایه و گرو، حساب بل‌ها، پرداخت‌ها، رسیدها و گزارش بدهی. عکس شخصی و آیکون‌های برنامه مستقیماً در ریشه پروژه قرار دارند؛ هیچ پوشه `assets` نیاز نیست.

## نصب در GitHub Pages
1. فایل ZIP را استخراج کنید.
2. تمام فایل‌های داخل ZIP را مستقیماً در ریشه مخزن GitHub آپلود کنید؛ فایل `index.html` باید در ریشه باشد. نیازی به آپلود یک فولدر پروژه یا فولدر `assets` نیست.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش Build and deployment، گزینه **Deploy from a branch**، شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
5. پس از انتشار، آدرس GitHub Pages را در Safari آیفون باز کنید.
6. از منوی Share گزینه **Add to Home Screen** را انتخاب کنید. آیکون برنامه با عکس شخصی شما طراحی شده است.

## فایل‌های اصلی
- `index.html` — برنامه
- `ghafoor-photo.jpeg` — عکس شخصی در ریشه پروژه
- `icon-192.png` و `icon-512.png` — آیکون برنامه با عکس شخصی
- `apple-touch-icon.png` — آیکون برای صفحه اصلی iPhone
- `manifest.webmanifest` و `service-worker.js` — امکانات PWA و کش آفلاین

## نکات مهم
- داده‌ها در حافظه محلی همان مرورگر/دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری ندارد.
- مرتب از بخش تنظیمات فایل JSON پشتیبان دانلود کنید.
- برای بازیابی، فایل JSON را در بخش تنظیمات انتخاب کنید. بازیابی اطلاعات فعلی را جایگزین می‌کند.
- رسیدها از طریق دکمه چاپ مرورگر قابل چاپ یا ذخیره به PDF هستند.
- Service Worker و نصب PWA در آدرس HTTPS مانند GitHub Pages فعال می‌شوند.
- ذخیره محلی به‌تنهایی نسخه پشتیبان نیست؛ پاک‌شدن داده‌های سایت یا تغییر دستگاه ممکن است اطلاعات را از بین ببرد.
- پیش از واردکردن سوابق مالی واقعی، فرایندهای کاری را با چند پرونده آزمایشی بررسی کنید.
